Shared buses are visual grouping conventions, not additional network components. Branches represent paths from each UPF to the core and from UE clients through each UPF to the collector; they do not imply that the collector scrapes UPFs.

Illustrative topology: the repository documents two gNBs; the third site and local routing are conceptual. NodePort can forward to a ready pod on another node. Controller and API host placement is not established.
