# Audit penyederhanaan konfigurasi suite vertikal

Audit ini mengikuti `run-vertical-suite.sh:19–39` dan profil yang diberikan pemilik. **J** adalah joint empat arm, **S** adalah scaling staircase, dan **M** adalah mobility empat arm dengan sembilan replika. Semua memakai pedestrian-detection. Bukti berasal dari pencarian simbol dan pembacaan kode lokal, serta render offline ketiga tahap. Status «terpasang» di bawah berarti dependensi runtime menurut kode dan konfigurasi rujukan. Kondisi kluster tidak diperiksa.

## Kesimpulan penghapusan dan sumber nilai

### Aman dihapus dengan konfigurasi dan image sekarang

1. Nilai tujuh field warisan dari **payload khusus Go**, setelah memastikan payload terpisah dari YAML Python dan metadata. Go tidak mengakses field tersebut di luar loader. Pertahankan whitelist hingga config lama selesai dimigrasikan. Bukti di tabel placement.
2. Salinan eksplisit `cpu_saturation: 0.8`, `max_metric_age_seconds: 120`, `scheduler_interval_seconds: 1.0`, `locality_weight: 0.4`, dan bobot 0.5/0.5/0/0 dari **ConfigMap statis Go** apabila image/default yang disebut dipin. Daftar kosong `zero_locality_nodes` juga ekuivalen. Root masih menyediakan bobot untuk renderer. `placement/internal/config/config.go:46–54,110–121`, `experiments/campaign.py:2251–2260`.
3. Pengulangan `--pod-share-scoring` dan `--prefer-close` pada wrapper J/M, dengan Go dan anchor tetap aktif. Parser masih menerima opsi tersebut. `experiments/campaign.py:2090–2107,2212`.
4. Alias `APP` dan uji alias, serta komentar kalibrasi lama dari config runtime jika riwayatnya tersimpan di dokumen. `experiments/campaign.py:36,84–87`, `experiments/test_pedestrian_workload.py:26`, `config.yaml:6–31`.
5. Dua query GPU/VRAM dari profil khusus CPU dengan bobot nol. Pertahankan key `gpu_nodes` dan empat dimensi selama schema mewajibkannya. `placement/internal/config/config.go:170–187`, `placement/internal/controller/controller.go:186–199`.
6. Pengulangan nilai numerik offloader yang persis sama dengan default dataclass atau server, jika kode/image dipin dan operator menyepakati default sebagai kontrak deployment. Konfigurasi endpoint, validasi dan policy tetap dibutuhkan. `offloader/server.py:209–262`, `offloader/policy.py:39–56`.

### Perlu keputusan pemilik

- Pertahankan desain joint dengan 1 Pod/15 s untuk proposed dan rate policy kluster untuk baseline. Membuat keduanya matched-rate akan menjadi kondisi eksperimen baru.
- Putuskan apakah `offloader/scaler.py`, mode Python, face-detection, default fallback lama, debug/smoke dan wrapper lama masih dibutuhkan untuk operasi manual dan reproduksi. Ketiadaan referensi dari suite hanya membuktikan ketiganya tidak bergantung pada entry point tersebut.
- Putuskan apakah telemetry GPU/vLLM, Grafana, inventori GPU dan schema empat bobot masih melayani workload lain. Penghapusan scrape job dan rules menyentuh monitoring bersama.
- Putuskan cara mendistribusikan ConfigMap dari file tunggal dan cara menyimpan nilai efektif dalam metadata. Penghapusan duplikat tanpa itu bisa menyembunyikan drift di image atau pemasangan manual.
- Pertahankan mapping 3/10 s selama usulan 1/5 s belum diputuskan. Bedakan threshold attainment kolektor aktif 500 ms dari default lokal 150 ms saat membaca histori.
